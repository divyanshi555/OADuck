# OA Duck at a glance

OA Duck is a focused coding-practice and online-assessment workspace. It combines a question library, an in-browser editor, code execution, monitored assessment sessions, performance history, and an AI-assisted review experience called Duck Insight.

## Product goals

- Make deliberate practice easier to start and easier to return to.
- Give learners feedback that is tied to their actual attempts.
- Simulate the constraints of technical online assessments.
- Give administrators one place to manage users, questions, test cases, and reference solutions.

## Main areas

| Area | Purpose |
| --- | --- |
| Landing page | Public introduction with sign-in and registration entry points. |
| Practice | Browse and solve coding questions. |
| Questions | Search and inspect the question library. |
| Assessment session | Solve a selected problem with timing and monitoring rules. |
| Profile | Review identity, statistics, and submission history. |
| Duck Insight | Request an explanation of an assessment attempt. |
| Admin | Manage users and question content. |

## Roles

Every account has either `USER` or `ADMIN` role. Users access practice and assessment experiences. Administrators additionally access dashboards, user management, question authoring, and test-mode controls.

:::tip
The root route redirects authenticated users to `/practice`. Unauthenticated visitors see the public landing page.
:::
